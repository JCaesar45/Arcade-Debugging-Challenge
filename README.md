# Arcade Debugging Challenge

Welcome to the **Arcade Debugging Challenge**, a fun and interactive way to practice understanding increment and decrement operators in JavaScript! This project features a vibrant, neon arcade-inspired theme to make your learning experience visually exciting.

## Overview

This project is designed as an educational tool to help developers and students master the use of prefix and postfix increment/decrement operators. The interface visually demonstrates how these operators work through a colorful, arcade-style UI.

---

## Features

- Vibrant neon glow arcade theme using CSS
- Interactive button to run JavaScript logic
- Visual display of variable states:
  - Counter
  - Score
  - Coins
  - Health
- Clear instructions for correcting buggy code
- Fun, game-like aesthetic to enhance engagement

---

## Demo

Click the **"Run Debug"** button to see the variables update based on correct operator usage

---

## How to Use

1. **Open the project**: Download or clone this repository.
2. **Open `index.html`** in your web browser.
3. **Read the instructions** provided on the page.
4. **Click the "Run Debug" button** to execute the JavaScript logic.
5. **Observe the updated variable values** reflecting correct increment/decrement operations.

## Technologies

- **HTML5** for structure
- **CSS3** for styling and arcade theme
- **JavaScript** for interactivity

## Customization

Feel free to customize the theme, add more variables, or extend the functionality! To modify the appearance:

- Update the JavaScript in the `<script>` tag for additional logic
- Enhance the interface with more arcade elements or animations
